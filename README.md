A tiny deterministic program that writes one very funny one-line office joke — the office printer has stopped giving error codes and now just says "no", which IT insists is not a malfunction but the printer setting boundaries.

## Run it

```sh
node main.ts
```

It writes the joke to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). No network, no randomness, no writes at runtime beyond the output file — run it twice and the bytes are identical.
